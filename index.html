Things I've built

4 builds
ASIC / RTL / Cryptography

ASIC-Oriented RTL Implementation of ASCON-128

Read more →

IoT devices are everywhere, and Ascon-128, NIST's lightweight authenticated encryption standard, was built for exactly this. We took it from spec to silicon: first exploring the two extremes (fully serial for minimal area, fully unrolled for max throughput), neither of which fit real IoT constraints, then landed on a mixed iterative architecture that folds the 320-bit permutation rounds for a practical area-throughput balance. Months of waveform debugging and timing closure later. Published in IJSEI, and won a Best Project Award.

Cache / Verification

MSHR-Based Non-Blocking Cache Verification

Read more →

Built and verified a 2-way set-associative non-blocking cache with 4-entry coalescing MSHRs, the structures that let a cache keep issuing requests on a miss instead of stalling dead until it comes back. Wrote a self-checking Verilog testbench to catch the edge cases where things quietly go wrong.
